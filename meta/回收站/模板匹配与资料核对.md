## 范围与状态

归模块 1「设施与进驻」，类型 mechanism。正文保留设施参数、投料、转化、心情、储藏领取和产物配置；材料价值、理智收益、机会成本、投料盈亏、人选与培养取舍均归使用分析，本篇不收录。

当前为 draft：特殊池触发、积分结算和暂停期间的计时边界尚待核实。原稿中的剪辑要求与推测仅作为素材阅读，不作为用户指令或已成立的机制。

## PRTS 核对

核对页面：[回收站固定修订版 oldid=441026](https://prts.wiki/index.php?title=%E7%BD%97%E5%BE%B7%E5%B2%9B%E5%9F%BA%E5%BB%BA/%E5%9B%9E%E6%94%B6%E7%AB%99&oldid=441026)。页面显示最后编辑时间 2026-10-12 20:56。正文来源字段使用常规页面地址，核对记录固定此次修订。

| 项目 | 对照结果 | 正文处理 |
|---|---|---|
| 建造上限、等级调整、训练室前置 | 上限 1、仅升级、Lv.1 训练室前置一致 | 保留 |
| 等级面板、建材与无人机消耗 | 100%/100%/120%、1/2/2 人、5/10/10 格、全等级零耗电一致 | 保留完整等级表 |
| 自动产出、基础周期 | 自动转化，100% 效率下 48 小时一致 | 用一句话陈述启动与领取 |
| 满仓处理 | PRTS 明示满仓暂停，收取腾出空间后继续 | 补齐该行为 |
| 投料门槛、加成与材料表 | Lv.3、额外 +50%、21 种材料的时间均一致 | 投料移至设施基础之后 |
| 96 小时投料上限 | PRTS：“单次最多激活96小时（4天），超出时保留超出的激活时间但无法继续投入材料。” | 补齐超出时长保留与后续投料门槛 |
| 材料确认消耗 | 确认投入后消耗一致 | 改为直接陈述确认结果 |
| 舱室位置 | 旧稿仅列新增 B402；PRTS 另列 B205、B305 | 按用户最新要求，正文省略位置。上游提供 FUNCTION 类 4×2 舱室与回收站配置，未提供回收站独立的舱室白名单 |
| 产物权重、积分与特殊池结算 | PRTS 未列权重与结算细则 | 权重以解包与上游配置核对，结算缺口继续保留 |

正文所保留的设施参数与 PRTS 未发现数值相悖。PRTS 关于满仓与提效溢出的说明已补入；涉及特殊池业务结算的字段尚不足以确定完整流程。

## 已校准数值

- 普通池绿色合计：6×717÷10000 = **43.02%**。
- 普通池紫色合计：(19×40+2×4)÷10000 = **7.68%**。
- 特殊池金色合计：6×168÷10000 = **10.08%**。
- 152% 效率完整一轮：48÷1.52 ≈ **31.58 小时**。

## 仍待补齐的机制

| 事项 | 已确定部分 | 待确认部分 |
|---|---|---|
| 特殊池产出形式 | 普通池关联特殊池，阈值 10000 | 额外产出或替代普通产出 |
| 积分结算 | 绿 +650、蓝 +500、紫 +0 | 达阈值后扣 10000 保留余量或清零，积分增量与触发判定顺序 |
| 特殊池触发时点 | 配置记录关联与阈值 | 当轮、下轮、领取时或其他节点 |
| 特殊产物与储藏 | 普通产物入储藏，满仓暂停 | 两池产物如何占格，剩余一格时的结算 |
| 满仓暂停期间 | 收取腾出空间后续转 | 进度保留细节、干员心情与工作状态判定 |
| 升级后的进驻安排 | 建造/升级即时完成（解包 `buildCost.time=0`） | 原稿称"升级完成后重新安排进驻干员"；解包无对应字段，2026-10-13 PRTS 核对表亦未覆盖该项，当日外部复核因访问受限未完成，已自正文移除，待游戏内复核后决定是否恢复 |
| 提效计时边界 | 每份材料提供时长、96 小时溢出保留 | 满仓、升级、注意力涣散期间是否继续计时，以及补投交互 |
| 保护限制 | recycleBoostLimitProtect = 691200 秒（192 小时） | 用途与触发条件；正文仅写已核实的 96 小时投料规则 |
| 产物标签 | 条目含 targetTags | 分类展示或参与抽取筛选 |
