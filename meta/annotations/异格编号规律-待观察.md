# 异格干员编号规律（待观察）

> 状态：**待观察，未实现**。本文只登记解包数据里可用于识别异格干员的 id 规律与证据，供名录人工维护参考；**不据此实现任何校验逻辑**——若将来要实现，先按本文「待观察」节复核规律是否仍成立。
> 登记日期 2026-09-10；数据基线 arkntools@`302105b`（干员 429 名）；名录见同目录 `term-rosters.json`（D18）。

## 规律（复合判据）

在 `meta/mirror/RIIC-Web/clean/operator-catalog.json` 的干员 id（`char_<编号>_<代号>`）上：

> **异格干员 ⟺ `1011 ≤ 编号 ≤ 1501` 且（代号以数字结尾，或 ∈ 白名单 { 维什戴尔 `wisdel` } ）**

对 2026-09-10 数据：判据结果与 PRTS「分类:异格干员」38 名名录**完全一致（零误报、零漏报）**。

### 分信号

1. **SP 专属编号段（最强信号）**：38 名异格恰好独占 1011–1052 连续段；1053–1501 整段空白；段外最小编号的干员是弑君者 `char_1502_crosly`，其后岁系列走 2012+、常规新干员走 4000+。窗口上界 1501 即取自弑君者之前；未来新异格预计接 1053+（或占用段内旧缺口），仍在窗口内。
2. **代号数字后缀（辅助信号）**：37/38 的代号以数字结尾，数字＝第几重异格（`lava2`＝炎狱炎熔；`chen2` 假日威龙陈／`chen3` 赤刃明霄陈＝同本体多重异格）。唯一例外维什戴尔 `char_1035_wisdel`（全新词根，不改名直接换词根），进白名单。
3. **干扰项与排除**：代号带数字的非异格干员仅三个——Lancet-2（`char_285_medic2`）、Castle-3（`char_286_cast3`，无人机型号名，编号不在窗口内）、暮落（`char_4025_aprot2`，PRTS 页面确认非异格，编号在四千段）。三者均被编号段条件排除。

## 待观察什么

- clean 刷新后出现**编号落在 1011–1501 窗口内的新干员**时：代号带数字后缀 → 大概率新异格，去 PRTS 分类页终审后补录 `term-rosters.json` 并更新 `asOf`；代号不带后缀 → 编号策略可能已变，本规律作废，回到纯 PRTS 人工核对。
- 段内缺口（1017/1018/1025/1037 等未实装槽位）被新干员占用时，按上条同样判断。
- 若异格编号将来越过 1501：窗口外的新异格会以「名录有而候选无」的形态暴露，届时上调窗口上界。
- 完整 character_table（D7「解包库自备抽取」落地后）是否出现显式异格字段可替代本规律——社区资料目前均指向 id 规律，未见公认 flag。

## 若将来实现（仅设计备忘，未实施）

三向差集探测器：本地候选（上述判据）vs `term-rosters.json` 名录 vs 干员目录——

- 候选 − 名录 ＝ 疑似新异格（人工 PRTS 终审）；
- 名录 − 候选 ＝ 不合规律的存量（人工信任项，须在名录 `note` 登记）；
- 名录 − 干员目录 ＝ render 已有硬失败（`term-rosters.json` 成员不在干员目录即报错）。

落点建议 `scripts/verify-skill-snapshot.mjs`（本库「数据级校验」的家）；不进 render 脚本，保持其纯渲染。
