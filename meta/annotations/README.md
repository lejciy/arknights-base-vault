# 受管名录增补（annotations）

> 官方术语表里有些类别**只给定义不给成员**（如「异格：包含所有异格干员」），但下游使用需要可枚举的名单。本目录存放这类**人工整理、外部来源、经核对**的名录，`scripts/render-skill-snapshot.mjs` 渲染 `类别.md`／`名册.md` 时自动合并，不改动 `meta/mirror/` 真源。

## 文件

| 文件 | 内容 |
|---|---|
| `term-rosters.json` | 术语名 → 名录：`source`（出处 URL）、`asOf`（核对日期）、`note`（口径与佐证）、`members`（成员，渲染时按星级降序＋名字码点序重排） |
| `异格编号规律-待观察.md` | 解包 id 识别异格的复合判据与证据（待观察、未实现；实现前先复核规律仍成立） |

## 维护约定

- 每条名录必须：外部可查证（`source`）、注明核对日期、与 `operator-catalog.json` 全量核对过（成员名必须存在，否则渲染报错）。
- 快照刷新（`clean` 更新 → 重跑 render）后，重放核对：新干员若属于某名录需补录，`asOf` 相应更新。
- 名录只承载「成员枚举」，不承载机制释义——机制归 `docs/2-干员技能/` 的释义层与 `docs/1-基础设定/`。
