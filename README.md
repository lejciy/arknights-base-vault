## 语料边界

- `docs/**/*.md` 是知识库正文，适合进入 RAG 索引。
- `docs/2-干员技能/` 例外：为 RIIC-KnowledgeAgent 生成的只读快照（2026-09-08 引入），请勿手改，更新走上游整体替换；规则见该目录 README。
- `meta/mirror/` 是外部仓库只读镜像（ArknightsInfraCalc 求解器规范，2026-09-08 自 `docs/1-基建产出基准/` 迁入；RIIC-Web 技能数据真源＋纯文本清洗版），不入 RAG。
- `meta/templates/` 是写作模板，不应作为玩家知识正文直接入库。
- `meta/agent/` 是 Agent 行为规范（RAG 系统提示词），不属于知识语料。
- `meta/外部参考/` 是外部仓库工程参考与血缘记录，不入 RAG。
- `external/` 是外部内容暂存区（练卡推荐原始口径等），不入 RAG。
- `TODO.md` 是协作待办，不应作为问答语料入库。
- `知识库模块设计.md` 是模块结构真源与内容索引，属治理文档，不入语料。
