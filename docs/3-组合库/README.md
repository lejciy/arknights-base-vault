# 组合库（模块3）

职责：定义和描述干员之间在基建场景下的组合方案——组合建议、替代关系、效率表现、组合原理。命名与成员关系的真源是 [组合注册表](组合注册表.md)，导航入口是 [组合总览](组合总览.md)。

## 目录导航

| 位置 | 内容 | 粒度 |
|---|---|---|
| `组合注册表.md` | 规范名/成员层级/完成状态（真源） | — |
| `组合总览.md` | 导航、互斥规则、243 示例 | — |
| `跨设施组合.md` | 跨设施组合汇总 | 设施向汇总 |
| `跨设施体系/` | 依赖中枢或跨设施资源的组合深稿 | 单组合 |
| `单站组合/` | 站内成套组合 + 贸易站/制造站组合汇总 | 单组合 + 设施向汇总 |
| `散件干员速查.md` / `高效率散件.md` | 散件侧 | 散件 |
| `标签速查.md` | 按功能标签找干员（44 标签全量，自动生成，真源在模块2 数据） | 功能向查表 |
| `歧义/` | 干员名消歧：子串同名对（自动生成）＋简称合称（人工维护），自模块2 迁入 | 查表 |

## 分层判据

按**设施跨度**分层：「去掉中枢和跨设施资源后，这个组合还成立吗？」成立 → `单站组合/`；不成立 → `跨设施体系/`。

## 引用规则

- 组合文档通过干员/技能名引用 `2-干员技能/` 快照，不重复描述技能运作原理。
- 新组合先在组合注册表登记规范名与成员层级，再落深稿。
