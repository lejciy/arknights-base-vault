# 叙拉古

> 2026-09-08 裁决：本组与但书解绑，命名与成员关系以 [[组合注册表]] 为准。原文档题《但书叙拉古链》，但书曾列为核心——现为**全基建核心散件、单走一站**，倍率与练度差异见 [[贸易站机制]]。

## 一句话结论

伺夜 + 贝洛内进驻同一贸易站，配合中枢八幡海铃（每个贸易站的叙拉古干员 +5% 效率，另带办公室公招加速），构成叙拉古贸易组。满配等效约 200% 贸易效率。

## 成套组成

| 干员 | 设施 | 练度 | 作用 |
|------|------|------|------|
| 伺夜 | 贸易站 | 精 2 | 叙事拉古同伴增益 |
| 贝洛内 | 贸易站 | 精 2 | 家族经营·β + 伺夜在场时的额外增益 |
| 八幡海铃 | 中枢 | 精 2 | 每个贸易站的叙拉古干员 +5% 效率 + 公招加速 |

## 与但书的关系（已解绑）

- 但书不再属于本组核心或必要成员；他的形态是**单走一站**（但书 + 订单效率工具人），违约倍率表（精 2 Lv.3 = 1.55 等）见 [[贸易站机制]]。
- 243 双贸易站下，叙拉古、龙舌兰组、但书单走、可露希尔带队**相互竞争贸易站位**。原文档「贸易站 1 = 但书 + 伺夜 + 贝洛内」的搭配示例随解绑**作废**，站位分配待按求解口径复核后重写。

## 缺人降级

- 缺伺夜或贝洛内 → 剩余一人 + 高效率散件；组增益受损，收益明显下降
- 缺八幡海铃 → 可以开，但失去中枢侧 5%×n 加成与办公室取向收益

## 与其他体系的关系

- 与龙舌兰组共存于 243 双贸易站（各占一站）
- 与感知信息组兼容——黑键可以放进叙拉古站做第三人
- 与喀兰贸易组、格拉斯哥帮组互斥（同属 meta_chain 互斥组，中枢位和体系定位冲突；互斥组成员构成待按注册表复核）
