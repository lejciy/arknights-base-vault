# 格拉斯哥帮组

## 一句话结论

格拉斯哥帮组是跨设施贸易组合：摩根与推进之王进驻同一贸易站，戴菲恩进驻控制中枢。推进之王本人没有贸易技能，精零即可作为摩根的加成条件；维娜·维多利亚精二后作为第三人提供自身效率。中等优先级贸易组合——低于叙拉古和喀兰贸易组，可作为替补方案。

## 启用条件

- 摩根必须精2（帮派指南针），与推进之王进驻同一贸易站。
- 戴菲恩精2进驻控制中枢。
- 推进之王精0即可，无练度要求。
- 缺摩根精2时不开。

## 建议用法

- 站位：摩根＋推进之王（＋维娜·维多利亚）进驻贸易站，戴菲恩进驻控制中枢。
- 维娜·维多利亚是第三人位增强，按持有情况补入。
- 取舍：叙拉古、喀兰贸易组的泛用性通常更优，本组多作为没有其核心时的替代方案。

## 成员与档位

技能事实：

- **摩根** 精2「帮派指南针」：同站每名格拉斯哥帮干员 +20% 订单获取效率；与**推进之王**同站时额外 +35%
- **维娜·维多利亚** 精2「外贸决议·β」：自身 +30%；同站存在格拉斯哥帮干员时额外 +10%
- **推进之王**：无贸易技能（名册中仅宿舍技能），在站内仅作为摩根的触发条件
- **戴菲恩** 精2（中枢）「运筹好手」：每个贸易站内的格拉斯哥帮干员 +10% 效率

| 干员 | 层级 | 设施 | 练度 | 作用 |
|------|------|------|------|------|
| 摩根 | 核心 | 贸易站 | 精 2 | 帮派指南针，主效率来源 |
| 推进之王 | 核心 | 贸易站 | 精 0 | 无贸易技能，触发摩根的 +35% 条件 |
| 戴菲恩 | 核心 | 控制中枢 | 精 2 | 运筹好手 |
| 维娜·维多利亚 | 次级 | 贸易站 | 精 2 | 外贸决议·β，第三人位增强 |

## 缺人降级

- 格拉斯哥帮组缺摩根精2 → 不开
- 格拉斯哥帮组缺推进之王 → 摩根失去 +35% 同站条件，按散件组合衡量
- 格拉斯哥帮组缺戴菲恩 → 少中枢侧每名格拉斯哥帮 +10%，仍可按单站组合运行

## 互斥与共存

- 格拉斯哥帮组 × 叙拉古 / 喀兰贸易组 / 怪猎中枢：体系互斥——四组合共享中枢资源线，只能同时开启一个。
- 格拉斯哥帮组 × 龙舌兰组：共存——不同贸易站各带一队。

## 数值锚点

- 本组暂无经确认的合计效率锚点，效率表现以技能事实表为准。

## 边界与误区

- 推进之王（☆6 先锋，仅宿舍技能）与维娜·维多利亚（☆6 近卫，持外贸决议）是**两名独立干员**，社区俗称「推王」两边都指，涉及贸易站时应先确认指哪一位（消歧见 [歧义-简称合称](../歧义/歧义-简称合称.md)）。
- 体系名「格拉斯哥帮组」是整体，不要拆开按字面解析成员。
