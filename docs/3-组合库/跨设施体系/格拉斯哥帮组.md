# 格拉斯哥帮组

> 命名与成员以 [[组合注册表]] 为准：核心为摩根精二、戴菲恩精二、推进之王精零，维娜·维多利亚精二为次级增强。注意推进之王（☆6 先锋，仅宿舍技能）与维娜·维多利亚（☆6 近卫，持外贸决议）是**两名独立干员**。

## 一句话结论

摩根与推进之王进驻同一贸易站，戴菲恩进驻控制中枢，构成格拉斯哥帮组。推进之王本人没有贸易技能，精零即可作为摩根的加成条件；维娜·维多利亚（独立干员）精二后作为第三人提供自身效率。中等优先级贸易组合——低于叙拉古和喀兰贸易组，可作为替补方案。

## 技能事实（2026-09-08 按 `2-干员技能/技能-贸易站.md` 快照核对）

- **摩根** 精 2「帮派指南针」：同站每名格拉斯哥帮干员 +20% 订单获取效率；与**推进之王**同站时额外 +35%
- **维娜·维多利亚** 精 2「外贸决议·β」：自身 +30%；同站存在格拉斯哥帮干员时额外 +10%
- **推进之王**：无贸易技能（名册中仅宿舍技能），在站内仅作为摩根的触发条件
- **戴菲恩** 精 2（中枢）「运筹好手」：每个贸易站内的格拉斯哥帮干员 +10% 效率

## 数值锚点

原《推王龙门》记录的 0.95 / 1.35 面板数值基于「推王＝维娜」的错误前提，**作废待重算**。上表技能事实为快照核对结果；组合面板需按当前成员构成重新结算（建议交求解器，不在本文手算）。

## 缺人降级

- 缺摩根精 2 → 不开
- 缺推进之王 → 摩根失去 +35% 同站条件，按散件组合衡量
- 缺戴菲恩 → 少中枢侧每名格拉斯哥帮 +10%，仍可按单站组合运行

## 与其他体系的关系

- 与叙拉古、喀兰贸易组互斥（meta_chain 互斥组）
- 叙拉古/喀兰贸易组的泛用性通常更优，本组多作为没有其核心时的替代方案
