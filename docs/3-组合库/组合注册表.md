# 组合注册表

> 模块3 组合定义总表与全库词表。单组合知识的真源在各组合深稿（正文＋front matter），本表为全库总览。

## 1. 全库词表

### 1.1 成员层级

| 层级 | 含义 |
|---|---|
| 核心 | 决定组合身份或启动主要机制的角色 |
| 重要 | 提供主要增益、关键分支或把基础形态提升到推荐形态的角色；可含「多选一、三选二」等分支要求 |
| 次级 | 能继续提高收益或作为常用替换，但不是优先补齐对象 |
| 挂件 | 本身不为目标设施直接提供效率，只为其他角色提供人数、标签、数值或计数 |

### 1.2 完成状态

| 状态 | 判断 |
|---|---|
| 已成型 | 所需核心已拥有并达到目标练度，所选重要分支也达到推荐形态 |
| 持有可启动、练度不足 | 启动所需角色均已拥有，但至少一名核心或所选重要分支未达到目标练度 |
| 缺核心、暂时无法启动 | 至少一名核心未拥有 |

### 1.3 产物

| 产物 | 含义 |
|---|---|
| 贸易 | 以订单获取效率与订单报酬为主要收益 |
| 赤金 | 贵金属制造配方 |
| 经验 | 作战记录制造配方 |
| 通用制造 | 可用于赤金、经验等多种制造配方 |
| 搓玉 | 源石碎片制造（只维护散件名单，不建组合） |
| 非生产 | 办公室、控制中枢等不以生产产物为目标的组合 |

### 1.4 层

| 层 | 判据 |
|---|---|
| 单站 | 去掉中枢和跨设施资源后，组合仍成立 |
| 跨设施 | 去掉中枢或跨设施资源（发电站、办公室、基建内成员计数等）后，组合不成立 |

### 1.5 互斥类型

| 类型 | 语义 |
|---|---|
| 同站 | 同一设施房间内不能同放 |
| 同设施 | 严格不能在相同设施内同时上班 |
| 资源竞争 | 共享有限资源（如控制中枢 5 人位），可挤占但非硬互斥 |

## 7. 全库边界

- 但书、可露希尔是全基建核心散件，不与任何纯效率角色绑定成固定组合；但书单走形态与违约倍率见 [但书](单站组合/但书.md)，可露希尔分档见 [可露希尔特别订单](单站组合/可露希尔特别订单.md)。
- 组合值不等于散件值。火神的高数值依赖同站角色：

```text
红云组：19 × 2 - 5 = 33%
泡泡组：19 × 3 - 5 = 52%
```

  52% 只能作为泡泡组内的火神收益说明，不能写成「火神单人 52%」。砾（红松林骑士组）、娜斯提（莱茵生命阵营）、深巡（深巡＋乌尔比安）同理，组合内数值不构成独立散件效率（[高效率散件](高效率散件.md)·使用口径）。
