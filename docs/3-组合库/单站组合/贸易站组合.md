# 贸易站组合

> 本文整理需要指定成员协作才能成立的贸易站组合。组合是基建安排建议，不替代按当前持有、练度和设施状态进行的精确计算；缺少核心成员时，应降级为普通散件或其他已能启动的组合。

## 使用边界

- 组合中的设施位置、核心成员和目标练度是成立条件；“重要”和“挂件”是可选增强，不要把它们误当成核心。
- 同一干员同时属于多个组合时，按已完整、收益更明确的组合安排站位。
- 订单上限、特殊订单和心情效果可以影响长期收益，但不能直接当作订单获取效率相加。

## 高效率组合

### 龙舌兰组

- **核心**：巫恋精二、龙舌兰精二。
- **搭配**：再安排至少一名精二、具备裁缝 β 等价技能的成员；当前可选柏喙、折光、明椒或卡夫卡。
- **用法**：巫恋、龙舌兰和达标裁缝共同进驻同一座三级贸易站。巫恋的技能会改变同站其他成员的效率计算，因此缺少达标裁缝时不要把巫恋单独当作本组合的完整形态。
- **边界**：龙舌兰的特殊订单效果是本组的一部分，不应改写成普通订单获取效率散件。

### 能天使组

- **核心**：能天使精二、蕾缪安精二，二人进驻同一座贸易站。
- **用法**：蕾缪安在能天使同站时获得额外订单获取效率，能天使负责稳定的订单获取效率；只有双核心都具备时才视为完整组合。
- **边界**：新约能天使和空弦不属于本组；二人属拉特兰组成员（见 [拉特兰](拉特兰.md)）。

### 拉特兰

- **核心**：新约能天使精二、蕾缪安精二；第三人选具备贸易效率的拉特兰干员，首选空弦精二。
- **用法**：新约能天使按同站拉特兰干员 +15%/人，蕾缪安与新约能天使同站合计 +45%；双核 60%，满配（＋空弦、满级宿舍）115%。详见 [拉特兰](拉特兰.md)。
- **边界**：新约能天使与能天使都不在「拉特兰」官方术语名单内——能天使作第三人不触发计数；蕾缪安为能天使组与本组的共同核心。

### 泡影国狩猎小队

- **核心**：焰狐龙梓兰精二、雷狼龙S空爆精二，二人各自进驻一座贸易站即可（同站或分站均可）。
- **用法**：焰狐龙梓兰「队长的自觉」提供订单上限 +3，并按基建内进驻贸易站的泡影国狩猎小队干员每人 +20%（含自身、不限同站）；雷狼龙S空爆「气氛组」+35%。双人合计 75%＋3 上限，分站时各自带队（焰狐龙梓兰 40%＋3、雷狼龙S空爆 35%）。详见 [泡影国狩猎小队](泡影国狩猎小队.md)。
- **边界**：术语第三人罗德岛隐秘队只能进驻宿舍与会客室，数不进计数；两人精二前在贸易站均无技能，未精二不启用。

### 叙拉古

- **核心**：伺夜精二、八幡海铃精二；重要成员为贝洛内精二。
- **分工**：八幡海铃进驻控制中枢，伺夜与贝洛内进驻同一座贸易站。贝洛内的贸易效果需要基建内有伺夜配合。
- **边界**：缺少控制中枢或贸易侧核心时，按单人技能重新判断，不视为本组可启动形态。

### 喀兰贸易组

- **核心**：灵知精二、银灰精二、孑精一。
- **分工**：灵知负责跨设施的喀兰协作，银灰与孑构成贸易侧核心；崖心精二、琳琅诗怀雅精二可作为订单上限适配成员。
- **边界**：订单上限是本组的辅助收益，不能单独写成固定订单获取效率；孑精一是本组贸易侧的目标练度，不能擅自提高为精二。

### 格拉斯哥帮组

- **核心**：摩根精二、戴菲恩精二、推进之王精零。
- **分工**：摩根与推进之王进驻同一座贸易站，戴菲恩进驻控制中枢；维娜·维多利亚精二可作为次级增强成员。
- **用法**：摩根的效率随同站格拉斯哥帮成员增加，并在推进之王同站时进一步增强；戴菲恩的效果取决于贸易站内的格拉斯哥帮成员数量。

### 鸿雪杜林组

- **核心**：鸿雪精二、绮良精二、图耶精二。
- **挂件**：至简、桃金娘、褐果、杜林、特克诺五名成员中放满四名，均精零即可；挂件不设独立培养目标。
- **用法**：鸿雪把基建内杜林族成员转化为贸易侧增益，挂件集合按持有情况补足。只有挂件而没有三名核心时，不称为可启动的鸿雪杜林组。三人可分驻不同贸易站不影响效率表现，同站按 绮良→鸿雪→图耶 进驻，4 赤金满配 160%；详见 [鸿雪杜林组](../跨设施体系/鸿雪杜林组.md)。

### 人间烟火组

- **核心**：乌有精二。
- **重要成员**：重岳精零、令精二、桑葚精二；夕精零、琴柳精二、截云精二、黍精二为次级成员，其余岁家干员（年、余、望）为挂件。
- **用法**：这是跨多个设施的组合——中枢与办公室产出全局资源人间烟火，乌有在贸易站按每点烟火 +1% 订单效率消费，满配 95 点＝95% 订单效率，优先与感知信息组混合使用；制造端终端（黍/截云）转化率低，不作推荐。详见 [人间烟火组](../跨设施体系/人间烟火组.md)。

## 低效率或过渡组合

### 企鹅物流

- **核心**：德克萨斯精二、拉普兰德精二同站；能天使精二是重要成员。
- **用法**：适合在能天使组尚未成形时作为过渡方案。德克萨斯与拉普兰德的同站协作是本组成立基础。
- **边界**：如果能天使组的双核心已经具备，能天使优先放入能天使组。

### 深巡＋乌尔比安

- **核心**：深巡精二；乌尔比安作为基建内挂件，精零即可且不设独立培养目标。
- **用法**：深巡进驻贸易站，乌尔比安在基建内时触发额外贸易收益。
- **边界**：乌尔比安不是贸易站散件；缺少乌尔比安时，深巡按自身技能判断，不把组合收益写成固定单人值。

## 全基建核心散件边界

- 但书、可露希尔是全基建核心散件，不与其他干员绑定成固定效率组合；但书单走形态与违约倍率见 [[但书]]，可露希尔分档见 [[可露希尔特别订单]]。
