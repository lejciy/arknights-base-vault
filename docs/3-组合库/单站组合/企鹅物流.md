# 企鹅物流

## 一句话结论

企鹅物流是单站贸易组合（低效率/过渡档）：德克萨斯＋拉普兰德同站协作（德狼路线），合计 65% 效率＋订单上限 +4。能天使＋蕾缪安（能蕾）属独立的能天使组，本文保留其路线机制作替代选择。德克萨斯精2不损失德狼效率——「恩怨」是初始技能，精2只新增「默契」。

## 启用条件

- 德克萨斯与拉普兰德同站是成立基础；拉普兰德精2（醉翁之意·β 订单上限 +4）。
- 德克萨斯精0即可用（恩怨初始解锁），精2更好且不损失效率。
- 缺拉普兰德 → 德狼不开；两条路线都缺核心 → 用日常散件替代。

## 建议用法

- 站位：德克萨斯＋拉普兰德＋第三散件（如裁缝 β）进驻同一贸易站，三人组可逼近一线水平。
- 替代选择（机制说明，深稿见对应组合页）：
  - 路线 B「能蕾」（属能天使组）：能天使精2（物流专家 +35%）＋蕾缪安精2（相伴 +20%，与能天使同行额外 +25%）——双人合计 80%，再搭配第三散件即可成形（深稿见 [能天使组](能天使组.md)）。
  - 路线 C「能蕾＋新约能天使」（属拉特兰组）：新约能天使精2 替代能天使，双人合计 60%，门槛更低（深稿见 [拉特兰](拉特兰.md)）。
- 布局：不与任何中枢体系冲突（不需要中枢干员）；与龙舌兰组、叙拉古在 243 双贸易站下共存，可占第二个贸易站。

## 成员与档位

| 干员 | 层级 | 练度 | 作用 |
|------|------|------|------|
| 德克萨斯 | 核心 | 任意（精 0 即可，精 2 更好） | 恩怨：与拉普兰德同站 +65% 效率，心情消耗 +0.3/h |
| 拉普兰德 | 核心 | 精 2 | 醉翁之意·β：德克萨斯同行时订单上限 +4 |
| 能天使 | 重要 | 精 2 | 见「建议用法」替代路线；能天使组成形时优先归能天使组 |

德克萨斯的技能结构：「恩怨」为精0初始技能（与拉普兰德同站 +65% 效率、心情消耗 +0.3/h），精2新增「默契」（与能天使同站心情消耗 −0.3/h），恩怨不会消失。当前环境下能天使与蕾缪安自成一组，德克萨斯的默契技能基本不触发。

## 缺人降级

| 缺谁 | 方案 |
|------|------|
| 德狼缺拉普兰德 | 不开 |
| 缺德克萨斯 | 无法走德狼，转能蕾路线（能天使组） |
| 能蕾缺能天使 | 新约能天使替补（双人 60%，转组拉特兰） |
| 能蕾缺蕾缪安 | 效率打折扣，不建议 |
| 两条路线都缺核心 | 用日常散件替代 |

## 互斥与共存

- 企鹅物流无同站/体系互斥。
- 与龙舌兰组、叙拉古在 243 双贸易站下共存——占第二个贸易站。
- 不占用控制中枢席位。

## 数值锚点

| 组合 | 站内效率 |
|------|---------|
| 德狼（德克萨斯 + 拉普兰德精 2） | 65% + 上限 +4 |
| 能蕾（能天使精 2 + 蕾缪安精 2，属能天使组） | 80% |
| 能蕾（新约能天使 + 蕾缪安，属拉特兰组） | 60% |

## 边界与误区

- 德克萨斯不需要压练度：精2只新增「默契」，「恩怨」始终是 65%，可以正常精2。
- 能天使与蕾缪安的完整组合是能天使组（不含新约能天使与空弦，二者属拉特兰组）；能天使组双核心具备时，能天使优先归能天使组。
