# 但书

> 定位以 [[组合注册表]] 为准：但书是**全基建核心散件、单走一站**，不与任何纯效率角色绑定成固定组合。本文收录单走形态、违约倍率与产出锚点。

## 一句话结论

但书（精 2）以「合同法＋违约索赔·β」把赤金订单改造为违约订单（+2 赤金 / 报酬 +1000），放大单笔订单价值；形态是**单走一站**——但书 + 两名订单效率工具人。不能与可露希尔同站（她的特别订单优先级更高，会抢走违约触发）。

## 成套组成

| 干员 | 设施 | 练度 | 作用 |
|------|------|------|------|
| 但书 | 贸易站 | 精 2 | 合同法＋违约索赔·β：违约订单追加赤金数与报酬 |
| 订单效率工具人 ×2 | 贸易站 | 按散件速查 | 拉高订单效率、缩短订单周期 |

## 违约订单机制

- 合同法：下笔赤金订单交付数 <4 即视为违约；违约索赔 α +1 赤金 / 报酬 +500，β +2 赤金 / 报酬 +1000（报酬与赤金数同步增加）。
- 佩佩、可露希尔、U-Official 的特殊订单「不视作违约订单」，不与合同法 / 违约索赔联动。
- 机制细节与特殊订单优先级见 [[贸易站机制]]·特殊订单。
