# 组合总览

> 命名与成员关系的裁决真源是 [[组合注册表]]（2026-09-08 引入，原练卡推荐《组合知识库》）。本文只做导航；凡与注册表冲突处以注册表为准。旧简称（巫恋核/灵孑/推王龙门等）不再作为规范组合名使用。

## 分层判据（2026-09-08 裁决 D4）

按**设施跨度**分层，一句话判据：去掉中枢和跨设施资源后组合还成立吗？
- 成立 → 单站组合；不成立 → 跨设施体系。

## 互斥规则

### meta_chain 互斥组（四选一）

中枢资源线互斥——以下组合共用同一 meta_chain 互斥组，只能同时开启一个：叙拉古、喀兰贸易组、格拉斯哥帮组、怪猎中枢。
> 本组成员构成以 [[组合注册表]] 为准。

### 其他互斥

- **感知信息组 + 龙舌兰组**：黑键不能和巫恋同贸易站
- **但书 + 可露希尔**：不能同贸易站（可露希尔订单抢但书触发）
- **中枢 5 人位竞争**：所有需要中枢干员的组合共享 5 个中枢位
- **深海猎人组 + 自动化组**：不能同制造站（清零效果优先生效）
