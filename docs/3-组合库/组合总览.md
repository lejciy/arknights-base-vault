# 组合总览

> 命名与成员关系的真源是 [[组合注册表]]。本文只做导航；凡与注册表冲突处以注册表为准。社区俗称作为别名收录在各组合条目（如巫恋组＝龙舌兰组、灵孑＝喀兰贸易组）。

## 分层判据

按**设施跨度**分层，一句话判据：去掉中枢和跨设施资源后组合还成立吗？
- 成立 → 单站组合；不成立 → 跨设施体系。

## 互斥规则

- **感知信息组 + 龙舌兰组**：满配黑键不与巫恋同贸易站（低感知黑键可作挂件第三人）
- **格拉斯哥帮组 + 龙舌兰组**：摩根不与巫恋同贸易站，分站各带一队
- **感知信息组 + 叙拉古**：中枢取向互斥——八幡海铃驻中枢使琴柳感染力失效，高制造&贸易效率与高人力二选一；黑键可进叙拉古站做第三人
- **感知信息组 + 人间烟火组**：絮雨与桑葚办公室二选一，令/夕心情档二选一（混合用法除外，见感知信息组·建议用法）
- **感知信息组 + 凯尔希·思衡托（精英干员挂件）**：办公室席位二选一——凯尔希·思衡托进驻期间絮雨无法同驻，感知链降档；迷迭香可兼担两侧
- **人间烟火组 + 叙拉古（人力取向）**：桑葚占用办公室且不提供联络速度，烟火取向与八幡海铃/焰狐龙梓兰联络光环下的公招刷新取向二选一（见人间烟火组·互斥与共存）
- **但书 + 可露希尔**：不能同贸易站（可露希尔订单抢但书触发）
- **中枢 5 人位竞争**：所有需要中枢干员的组合共享 5 个中枢位
- **能天使组 + 拉特兰**：蕾缪安为两组合共同核心，只能进驻一座贸易站
- **企鹅物流 + 能天使组**：能天使为两组合共同成员，能天使组双核具备时优先归能天使组
- **深海猎人组 + 自动化组**：不能同制造站（清零效果优先生效）
- **承曦格雷伊 + 驻发电站小车体系**：「晨曦」要求其他发电站无作业平台，与阿兰娜（机械精通）、布丁（超频）等把小车驻发电站的体系同设施互斥（红脸 0 心情的作业平台不阻断）
- **归零通则（自动化组 × 常规生产力组合）**：凡进驻制造站、以常规生产力技能输出的组合不能与归零类同制造站；豁免与可同站队友见 [自动化](../2-干员技能/释义/自动化.md)，分站带队即可并行
- **挂件位竞争**：S.E.E.S.组、莱茵生命阵营、凯尔希·思衡托（精英干员挂件）、鸿雪杜林组（杜林挂件）等计数体系共享基建挂件空位（可挤占非硬互斥）
