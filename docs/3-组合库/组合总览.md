# 组合总览

> 命名与成员关系的真源是 [[组合注册表]]。本文只做导航；凡与注册表冲突处以注册表为准。社区俗称作为别名收录在各组合条目（如巫恋组＝龙舌兰组、灵孑＝喀兰贸易组）。

## 分层判据

按**设施跨度**分层，一句话判据：去掉中枢和跨设施资源后组合还成立吗？
- 成立 → 单站组合；不成立 → 跨设施体系。

## 互斥规则

### 体系互斥组（四选一）

中枢资源线互斥——以下组合共享同一中枢体系资源线，只能同时开启一个：叙拉古、喀兰贸易组、格拉斯哥帮组、怪猎中枢。
> 本组成员构成以 [[组合注册表]] 为准。

### 其他互斥

- **感知信息组 + 龙舌兰组**：满配黑键不与巫恋同贸易站（低感知黑键可作挂件第三人）
- **但书 + 可露希尔**：不能同贸易站（可露希尔订单抢但书触发）
- **中枢 5 人位竞争**：所有需要中枢干员的组合共享 5 个中枢位
- **能天使组 + 拉特兰**：蕾缪安为两组合共同核心，只能进驻一座贸易站
- **深海猎人组 + 自动化组**：不能同制造站（清零效果优先生效）
- **归零通则（自动化组 × 常规生产力组合）**：凡进驻制造站、以常规生产力技能输出的组合不能与归零类同制造站；豁免与可同站队友见 [自动化](../2-干员技能/释义/自动化.md)，分站带队即可并行
- **挂件位竞争**：S.E.E.S.组、莱茵生命阵营、凯尔希·思衡托（精英干员挂件）等计数体系共享基建挂件空位（可挤占非硬互斥）
