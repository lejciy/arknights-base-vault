# 干员技能参考（模块2）

职责：提供基建技能原文真源，并按需解释少数高频误读技能的特殊机制。本目录是 `scripts/render-skill-snapshot.mjs` 从 `meta/mirror/RIIC-Web/clean/` 数据**全量生成的只读快照**，请勿手改；全量真源、清洗过程与刷新口径见 `meta/mirror/RIIC-Web/`。

## 内容导航

| 文件 | 内容 |
|---|---|
| `技能-*.md` ×9 | 按设施分片的技能原文：制造站113 / 贸易站94 / 控制中枢90 / 宿舍86 / 会客室73 / 办公室45 / 发电站41 / 训练室108 / 加工站105 条技能 |
| `名册.md` | 全部 429 名干员的边界闭包（星级/职业/有技能的设施/所属组） |
| `技能等价组.md` | 84 组「同效不同名」技能（如裁缝·β ＝ 手工艺品·β ＝ 鉴定师的手段）及全部持有者 |
| `类别.md` | 官方术语表 82 条：干员组成员、全局资源（感知信息/人间烟火/木天蓼/热情值/外势/工程机器人等）、特殊叠加规则的权威定义 |
| `歧义-子串对.md` | 子串同名对 31 组（自动生成，如「临光 ⊂ 耀骑士临光」） |
| `歧义-简称合称.md` | 简称合称消歧（推王/德狼/能蕾/银崖等，人工维护）＋官方同名组 |

数据规模：干员 429 / 基建技能 755 / 术语 82。数据出处为 [RIIC-Web](https://github.com/KnightCodeSquareMatrix/RIIC-Web)（arkntools 游戏解包数据）。技能分类以官方标签为准；`operator-skill-text.json`、`skill-terms.json` 为 `clean/` 的静态副本。

## 查询与引用

按设施使用 `技能-*.md`；按干员使用 [名册](名册.md)；同效技能使用 [技能等价组](技能等价组.md)；术语使用 [类别](类别.md)；歧义使用 [歧义-子串对](歧义-子串对.md) 与 [歧义-简称合称](歧义-简称合称.md)；按功能找干员使用模块3 的 [标签速查](../3-组合库/标签速查.md)。

技能原文按设施分片维护，普通干员与技能查询入口由现有结构化数据及后续索引派生，不为每名干员建立人工说明页。人工解析只覆盖快照与官方术语仍无法回答、且存在高频误读的少数技能或特殊机制，使用 `meta/templates/tpl-特殊技能释义.md`；释义页不承载组合归属、替代关系、培养评价或场景推荐——分别归模块3和模块6。

`类别.md` 同时承担模块1「资源组合总览」中全局资源与叠加规则的定义来源。
