# 产出常数表

> 玩家口径的产出核算常数注册表：产出总公式、普通产线基准产出、无人机折算系数与特殊组合锚点。本文只固定数字，机制语义见各设施机制篇，组合构成与效率论证见模块3。（2026-09-09 自求解器镜像 `EFFICIENCY_MODEL` / `TRADE_COMMUNITY_UNIT_OUTPUT` 提炼，普通产线数值已按 PRTS 订单数据独立推导核对）

## 产出总公式

> 产出/日 = 基准产出数值 × 总效率 × 在岗时长占比（/24h）

- 总效率的构成与叠加次序见 [[buff叠加模型]] 与各设施机制篇。
- 实体产出与无人机额外产出**分开计算再相加**：无人机折算效率见 [[发电站机制]]·产出折算，不与房间效率重复计算。

- **每赤金固定 500 龙门币**：高阶贸易只放大单笔订单的赤金数与总时长，不改变单位赤金产出比（见 [[贸易站机制]]·谈判策略）。
- 订单分布与档位时长见 [[贸易站机制]]·贵金属订单的生成概率；三档贸易锚点即由该分布严格推导。
- **作战记录等级经验**：基础 200 / 初级 400 / 中级 1000 点每份；按份数折算 1.0 效率日产为 基础 6400 / 初级 7200 / 中级 8000 点经验，基准锚定中级（8 份 × 1000 = 8000）。简报口径见 [[基建生产关系]]·三日报表。
- 搓玉链换算（600 玉 = 120 固源岩＋9.6 万龙门币，1 理智 ≈ 1.03 玉）见 [[基建生产关系]]·搓玉换算口径；场景论证见 [[搓玉]]（模块6）。

## 无人机折算

- **480 架/日 = 1.0 效率**：投入无人机数 ÷ 480 = 作用于该产线的等效效率；满发电全投即 E/2。推导与互证见 [[发电站机制]]·产出折算。
