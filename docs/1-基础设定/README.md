## 写作规范

- 模板：`meta/templates/tpl-基础设施.md`
- front matter：`tags` / `domain` / `prts_ref`（PRTS 页面链接）/ `source` / `last_updated`；外部引入加 `imported`
- 机制文档只写事实与公式，场景取向与优先级判断归模块6
- 版本叙事不落语料：「自『xx』版本起……」「截至 xx 版本」等阶段性/历史性描述一律不写，只保留当前版本有效的事实（时效由 front matter `last_updated` 锚定；PRTS 概率数据自带的「更新于」日期可保留）
