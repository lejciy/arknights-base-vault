# 基础设定（模块1）

职责：所有运算和决策的底层物理规则与事实框架——机制公式、设施面板、基础资源链。长期稳定，基建玩法改版时才整体调整。模块边界与归属判断见根目录《知识库模块设计》。

## 分区导航

| 分区 | 内容 | 判据 |
|---|---|---|
| `设施与进驻/` | 基建总览（进驻状态/座椅制/批量编辑）+ 基建建设（解锁/建材/耗电/改建）+ 信赖值、活动室 + 9 类设施面板与子系统 | 「某类设施的面板或子系统」 |
| `结算规则/` | 跨设施的计算规则（技能结算次序等）；星级技能解锁规则见 `2-干员技能/技能-*.md` 头部投影 | 「跨设施的计算规则」 |
| `资源体系/` | 基建生产关系（产物转化全链、效率到产出换算与倒推、三日报表读法、赤金供需平衡、链上缓冲、搓玉换算）+ 产出常数表（产出总公式、普通产线与特殊组合基准产出锚点、无人机折算） | 「可生产可消耗的东西」 |

引用优先指向具体标题；组合归属与场景取向分别回指模块3和模块6。

全局资源（感知信息/人间烟火/木天蓼/热情值等干员生产的中间资源）的生产、消费与转化关系归模块3（`3-组合库/` 的全局资源注册，载体待建）；基础资源的用量常数仍归本模块。
