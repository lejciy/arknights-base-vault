# 基建布局（模块7）

职责：「基建布局 ↔ 产出倾向」的简单查表库——只回答「这个布局是什么、产出偏什么」，不承载经验论证（为什么选它归模块6）。

## 文档导航

- [布局总表](布局总表.md) —— 243 / 252 / 333 / 153 等布局的设施配比、电力构成（810 平衡锚点）、产出倾向、吞吐结构与典型适配组合。

## 字段定义

| 字段 | 说明 |
|---|---|
| 设施配比 | 贸易/制造/发电数量（代号即配比，如 243 = 2 贸易 4 制造 3 发电） |
| 电力构成 | 各等级发电站供电组合 |
| 产出倾向 | 资源侧重（龙门币/赤金/经验/合成玉） |
| 吞吐结构 | 制造赤金产能 ↔ 贸易吞吐的上下游关系 |
| 典型适配组合 | 仅列组合名（适配细节归模块3） |
