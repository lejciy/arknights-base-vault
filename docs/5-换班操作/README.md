# 换班操作（模块5）

职责：提供换班操作的具体步骤和手法——纯粹的「动作库」，不绑定具体场景或资源倾向。

换班方式分三种，各自独立成文（写作骨架见 `meta/templates/tpl-换班方式.md`）：定时换班、自动轮换、动态换班；本模块先落方式篇与支撑页。

## 文档导航

- [自动轮换](自动轮换.md) —— 游戏内置的换班方式：红脸触发、按设施整队替换、干员休整配套；含替补队列配置策略与跨设施体系的错班取舍。
- [定时换班班次结构](定时换班班次结构.md) —— 定时换班的班次结构原理：三组人怎么分班、为什么 12+6+6，含单设施班型。
- [队列轮换](队列轮换.md) —— 游戏内队列功能的动作篇：手动编辑、队列轮换细则、干员休整、锁定编辑的操作步骤与判定规则。

游戏内操作机制的权威事实（批量编辑 3 队列轮换、切换生效条件、干员休整、锁定编辑、座椅制/暖机重置）见 `1-基础设定/设施与进驻/基建总览.md`，本模块引用、不复制。
