# 队列轮换

> 来源：罗德岛基建·进驻方法/批量编辑（PRTS，抓取于 2026-09-08；语料 `external/prts_罗德岛基建.md` L174-226）。本文是游戏内队列功能的**动作篇**：操作步骤与判定规则；结算后果（座椅制、暖机重置等机制事实）见 `1-基础设定/设施与进驻/基建总览.md`，本文引用、不复制。

## 一句话

游戏内置的换班动作库：手动编辑逐位进驻，队列轮换批量切换工作区，干员休整自动填宿舍，锁定编辑保护常驻位。

## 手动编辑（逐位操作）

入口：点击设施进驻信息 / 进驻总览 → 角色配置界面。

1. 在角色配置界面直接选择干员并任意排序，**确认后所选干员依序从第 1 位起排列进驻**。
2. 设施原干员被撤出；进驻前后都在该设施的干员，按位置决定是否被撤出（座椅制，见基建总览）。
3. 不进入角色配置界面的撤出方式：通过设施进驻信息**按位撤出**（不影响其他位置的干员）或**全部撤出**。

适用前提：需要精确控制每个位置（如按位序触发菲亚梅塔「患难之交」类技能）时用按位操作，其余场景优先批量编辑。

## 队列轮换（工作区批量切换）

自「揭幕者们」版本（2024/11/1）起可用。适用范围：**工作区设施**（控制中枢、产出设施、会客室、办公室）。

### 编辑预设队列

- 每个设施最多 **3 个预设队列**；如普通进驻一样为队列编辑并保存进驻情况。
- 「新增预设工作队列」：所有干员均不在该设施任一队列中时，按当前已进驻干员生成队列；否则创建空队列。
- 处于任一队列中的干员，在角色配置界面右上角显示**蓝色标记**。

### 切换队列

- **手动切换**：从预设队列中手动指定一个应用。
- **快速切换**：系统自动选队列，判定优先级为——
  1. 所有干员均未处于训练室的训练位（无论是否正在专精）；
  2. 总心情比例最高；
  3. 队列序号靠前。
- 切换限制（注意事项）：
  - 无法应用**空队列**；无法应用**有干员正在训练室训练**的队列。
  - 若当前工作干员与所选队列干员相同（**即使位置不同**），视为该队列"应用中"，无法切换。
  - 干员若位于训练位或处于**注意力涣散**状态，无法通过快速切换应用其所在队列——需先处理该干员。
  - **干员不能同时存在于宿舍锁定区和预设队列**（互斥，见下）。

### 全局批量应用

入口：**代办事项**或**进驻总览**中的「队列轮换」。对所有"存在未进驻干员或注意力涣散干员"的工作区设施各执行一次快速切换——一句话：一键全站轮换。

## 干员休整（宿舍批量进驻）

入口：代办事项或进驻总览中的「干员休整」。

- 自动指定最多与**宿舍空闲位置数**相同的"未进驻且心情未满"干员，按心情比例由低至高进驻空闲位。
- 位置优先级：氛围值高 ＞ 楼层靠上 ＞ 宿舍内位置靠前。
- 自「相见欢」版本起，仅当休整所安排位置中存在**其他干员**时才移出该干员（心情已满者不再被强制移出）。

## 锁定编辑（宿舍常驻位保护）

自「相见欢」版本（2025/1/22）起可用。在进驻总览中锁定宿舍位，限制该位置的进驻。

- 锁定后宿舍分为**锁定区域与非锁定区域**：干员休整仅在非锁定位置进行。
- 手动编辑单个宿舍时，**同时只能编辑其中一个区域**，进驻上限受该区域位置数限制。
- 锁定区域干员显示「锁定中」标记，进驻其他类型设施（活动室除外）时需**二次确认**。
- 锁定编辑**不影响**后勤技能生效；锁定区与预设队列互斥（同一干员不能两边都占）。

## 手法选择速查

| 目标 | 动作 |
|---|---|
| 全站日常换班 | 代办事项 → 队列轮换（全局快速切换）+ 干员休整 |
| 单设施换队 | 进驻总览 → 手动/快速切换 |
| 精确控制位置 | 角色配置界面手动编辑 / 按位撤出 |
| 保留宿舍常驻奶妈/资源位 | 先锁定编辑，再执行休整与轮换 |
